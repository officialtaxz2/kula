# Kula (fork)

Fork of [c0m4r/kula](https://github.com/c0m4r/kula), a lightweight Linux server monitoring tool.

Slight design changes: a one-row header with a command menu, calmer charts, and "Show chart data controls" on by default.

Includes a setup script for installation and updates: `git pull && sudo bash deploy/setup.sh` (see [deploy/](deploy/)).
